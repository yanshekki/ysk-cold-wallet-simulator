# Security

Report a security issue by opening a GitHub issue on [yanshekki/ysk-cold-wallet-simulator](https://github.com/yanshekki/ysk-cold-wallet-simulator). Describe the impact and the versions. Do not include a live seed, a passphrase, or a keystore, including a test secret from a phone.

This repository does not publish a separate disclosure address.

The public statement of what CWS protects and what it leaves open is [docs/security.md](docs/security.md). Seeds are not absolutely safe. CWS has no secure element.
