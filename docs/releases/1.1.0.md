## English

CWS is a phone simulator for developers and wallet teams testing interoperability with selected Ledger, Trezor, and OneKey Bluetooth models. It is not a secure element. Ledger, Trezor, and OneKey do not endorse it. Do not use it to hold real digital assets.

**Seeds are not absolutely safe.** The public statement is [docs/security.md](https://github.com/yanshekki/ysk-cold-wallet-simulator/blob/main/docs/security.md).

### What this version is

1.1.0 (build 6) is the public source tree for the phone app, the workspace packages, and the macOS proxy. Signing identities and keystores are not in git.

A release build asks the OS authenticator before reveal, import, save, sign, and seed export. Recovery phrases are not written to the clipboard. Android release sets `FLAG_SECURE` on secret screens. iOS warns on a reported capture and does not black the live image.

These compatibility choices remain, because closing them stops wallets from connecting or from listing accounts:

- WebHID has no command allowlist.
- The local trezord bridge reflects the request `Origin`.
- Address and extended-public-key listing stays silent.
- The stored entropy item does not prompt on every read.

Known gaps that 1.1.0 does not close: Phantom may not finish unlock, Rabby’s camera may fail to scan in some setups, Avalanche Core may not list X and P accounts end to end, and OKX may not show balances for an imported account. Ledger Live’s genuine-device check is not expected to pass.

The October 2026 handset check was a debug build on Android 16 (`versionName` 1.0.4, the code this version publishes). It did not install a release build, and it did not show the release authenticator. The record is [docs/testing.md](https://github.com/yanshekki/ysk-cold-wallet-simulator/blob/main/docs/testing.md).

### 本版本是甚麼

1.1.0（組建編號 6）是手機應用程式、工作區套件及 macOS 代理程式的公開原始碼。簽署身份與金鑰庫不在 git。

正式組建在顯示、匯入、儲存、簽署及匯出種子之前，會要求作業系統認證。助記詞不會寫入剪貼簿。Android 正式組建在秘密畫面設定 `FLAG_SECURE`。iOS 在系統報告截圖時顯示警告，不會把即時畫面塗黑。

下列相容選擇仍然保留，因為關閉它們會令錢包無法連線或無法列出帳戶：

- WebHID 沒有指令允許清單。
- 本機 trezord 橋接器會反映請求的 `Origin`。
- 地址與擴展公鑰的列出保持靜默。
- 儲存的熵項目不會在每次讀取時提示。

1.1.0 沒有結束的已知缺口：Phantom 可能無法完成解鎖；在部分環境 Rabby 的相機可能掃不到；Avalanche Core 可能無法完整列出 X 與 P 帳戶；OKX 可能無法顯示已匯入帳戶的資產餘額。不應期望 Ledger Live 的正品檢查通過。

2026 年 10 月的實機檢查，是在 Android 16 上安裝除錯組建（`versionName` 1.0.4，即本版本所發佈的程式）。該次沒有安裝正式組建，亦沒有顯示正式組建的認證提示。紀錄見 [docs/testing.md](https://github.com/yanshekki/ysk-cold-wallet-simulator/blob/main/docs/testing.md)。
