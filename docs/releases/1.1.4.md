# CWS 1.1.4 (build 10)

YSK Limited · phone `hk.ysk.cws` · CWS Proxy `hk.ysk.cws.proxy`

Product: https://ysk.hk/products/ysk-cold-wallet-simulator

This note covers what landed after 1.1.3 (build 9): the copy-phrase and copy-share buttons are gone. It does not attach binaries. Signing identities and keystores are not in git. Seeds are not absolutely safe, and they are not hardware-wallet safe.

## English

CWS is a phone simulator for developers and wallet teams testing interoperability with selected Ledger, Trezor, and OneKey Bluetooth models. It is not a secure element. Ledger, Trezor, and OneKey do not endorse it. Do not use it to hold real digital assets.

**Seeds are not absolutely safe.** The public statement is [docs/security.md](https://github.com/yanshekki/ysk-cold-wallet-simulator/blob/main/docs/security.md). The 1.1.3 baseline still applies.

### What 1.1.4 changes

- The recovery-phrase grid and the recovery-share grid no longer show a copy button. On the vault backup sheet the labels were “Copy phrase” and “Copy share” (繁體中文（香港）: 「複製助記詞」 and 「複製份額」). On generate, the phrase grid used the same control. Tapping it did not write the secret. `clipboardWriteAllowed('secret')` stays false, so a phrase, a share, and entropy hex are still refused. Addresses, device names, and console log text can still be copied. Import still reads the clipboard only after Paste is confirmed, then clears it when the clipboard still holds that text.
- Tapping the entropy hex on the generate screen still explains that the value stays on the screen. That text is not a copy button.
- The device screen shows **Device id** (繁體中文（香港）: **裝置識別**), the same Bluetooth id CWS Proxy uses to lock the phone. CoreBluetooth does not give that id to the advertising phone, and Android does not expose it either, so the proxy writes it when it sees the phone. Until then the row is an em dash. Copy device id sits next to Copy UUID. Seeds are not absolutely safe.

## 繁體中文（香港）

CWS 是一款手機模擬器，供開發者及錢包團隊測試與指定 Ledger、Trezor 及 OneKey 藍牙型號的互通。它不是安全元件。Ledger、Trezor 及 OneKey 均未認可本軟件。請勿以本軟件保管真實數碼資產。

**種子並非絕對安全。** 公開說明見 [docs/security.md](https://github.com/yanshekki/ysk-cold-wallet-simulator/blob/main/docs/security.md)。1.1.3 的基線仍然適用。

### 1.1.4 改變了甚麼

- 助記詞格子與還原份額格子不再顯示複製按鈕。種子庫的備份表原先是「複製助記詞」與「複製份額」。產生種子時，助記詞格子用同一個控制。按下它不會寫入秘密資料。`clipboardWriteAllowed('secret')` 仍為否，因此助記詞、份額與熵的十六進位仍然被拒絕。地址、裝置名稱及主控台紀錄文字仍可複製。匯入仍只在確認貼上之後才讀剪貼簿，並在剪貼簿仍是該段文字時把它清掉。
- 在產生畫面按下熵的十六進位，仍會說明該值留在畫面上。那段文字不是複製按鈕。
- 錢包畫面顯示**裝置識別**，就是 CWS Proxy 用來鎖定電話的藍牙識別碼。CoreBluetooth 不會把這個識別碼交給正在廣播的電話，Android 亦不會把它交給一般應用程式，所以代理程式見到電話時寫入。尚未收到之前，該行是破折號。複製裝置識別放在複製 UUID 旁邊。種子並非絕對安全。
