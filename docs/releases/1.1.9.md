# CWS 1.1.9 (build 15)

YSK Limited · phone `hk.ysk.cws` · CWS Proxy `hk.ysk.cws.proxy`

Product: https://ysk.hk/products/ysk-cold-wallet-simulator

This note covers what landed after 1.1.8 (build 14): Sunday true-device protocol parity for Ledger Ethereum app 1.24.0. It does not attach binaries. Signing identities and keystores are not in git. Seeds are not absolutely safe, and they are not hardware-wallet safe.

## English

CWS is a phone simulator for developers and wallet teams testing interoperability with selected Ledger, Trezor, and OneKey Bluetooth models. It is not a secure element. Ledger, Trezor, and OneKey do not endorse it. Do not use it to hold real digital assets.

**Seeds are not absolutely safe.** The public statement is [docs/security.md](https://github.com/yanshekki/ysk-cold-wallet-simulator/blob/main/docs/security.md). The 1.1.8 Trezor 2.13.1 baseline still applies.

### What 1.1.9 changes

- Ledger Ethereum **1.24.0** ([release](https://github.com/LedgerHQ/app-ethereum/releases/tag/1.24.0), [`doc/apdu.md`](https://github.com/LedgerHQ/app-ethereum/blob/1.24.0/doc/apdu.md), [`doc/tlv_structs.md`](https://github.com/LedgerHQ/app-ethereum/blob/1.24.0/doc/tlv_structs.md)).
- SIGN_TX on a reported app ≥ 1.24.0 rejects trailing bytes after a complete RLP item, non-canonical RLP, and integer leading zeros on nonce / gas / value / chainId / v (`0x6A80`, V-363, `check_integer` in `eth_ustream.c`). Canonical payloads still sign. Pre-1.24.0 still slices the prefix.
- Personal-sign reads a full u32 length. A length with the high 16 bits set is rejected, not truncated (V-030). The 16384 cap stays. ≥ 1.24.0 uses `0x6A80`.
- EIP-712 V2 `P2=02` is isolated from V1 (`0x6980` mixed flow). Schema + values hash-and-sign (raw review) matches the Ether Mail digest. Full ERC-7730 clear-sign stays KEEP.
- `ledgerVersionIndex.json` lists 1.24.0 for Nano X / Stax / Flex / Gen5 apps Manager publishes. The by-target snapshot default stays **1.22.5**.
- Trezor is still 2.13.1 (`required: false`). OneKey firmware pins are unchanged. CWS Proxy remains 1.1.6 (build 12).

### 1.1.9 改變了甚麼

- Ledger Ethereum **1.24.0**（[發行說明](https://github.com/LedgerHQ/app-ethereum/releases/tag/1.24.0)、[`doc/apdu.md`](https://github.com/LedgerHQ/app-ethereum/blob/1.24.0/doc/apdu.md)、[`doc/tlv_structs.md`](https://github.com/LedgerHQ/app-ethereum/blob/1.24.0/doc/tlv_structs.md)）。
- 回報版本 ≥ 1.24.0 時，SIGN_TX 會拒絕完整 RLP 之後的尾隨位元組、非規範 RLP，以及 nonce／gas／value／chainId／v 的整數前導零（`0x6A80`，V-363，`eth_ustream.c` 的 `check_integer`）。規範 payload 仍會簽署。1.24.0 之前仍會截取前綴。
- Personal-sign 讀完整 u32 長度。高 16 位元有值時會拒絕，不會截斷（V-030）。上限仍為 16384。≥ 1.24.0 使用 `0x6A80`。
- EIP-712 V2 `P2=02` 與 V1 隔離（混用為 `0x6980`）。Schema + values 雜湊簽署（原始檢視）對齊 Ether Mail digest。完整 ERC-7730 clear-sign 仍為 KEEP。
- `ledgerVersionIndex.json` 為 Manager 有列出的 Nano X／Stax／Flex／Gen5 應用程式加入 1.24.0。by-target 快照預設仍為 **1.22.5**。
- Trezor 仍為 2.13.1（`required: false`）。OneKey 韌體釘選不變。CWS Proxy 仍為 1.1.6（組建編號 12）。
