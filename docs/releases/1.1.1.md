# CWS 1.1.1 (build 7)

YSK Limited · phone `hk.ysk.cws` · CWS Proxy `hk.ysk.cws.proxy`

This note covers the hot-wallet baseline in #70 and #71. It does not attach binaries. Signing identities and keystores are not in git. Seeds are not hardware-wallet safe.

## English

CWS is a phone simulator for developers and wallet teams testing interoperability with selected Ledger, Trezor, and OneKey Bluetooth models. It is not a secure element. Ledger, Trezor, and OneKey do not endorse it. Do not use it to hold real digital assets.

**Seeds are not hardware-wallet safe.** The public statement is [docs/security.md](https://github.com/yanshekki/ysk-cold-wallet-simulator/blob/main/docs/security.md).

### What 1.1.1 changes

- A release build stores entropy and SLIP-39 shares with `requireAuthentication`. Debug skips that prompt only when `__DEV__` is true. The first successful read stays in memory until lock. Reveal and backup read the keychain again.
- The recovery phrase is not written to the clipboard. Import reads the clipboard only after Paste is confirmed, then clears it when the clipboard still holds that text.
- Android release sets `FLAG_SECURE` on secret screens. The debug skip is `__DEV__` only.
- iOS blurs the app switcher and warns on a reported capture. Warn-only is intentional: blanking the live image also blanks mirroring and Control Center.
- The phone confirms a public account or extended-public-key read. One confirm covers that read and the next 15 public reads for 60 seconds. It does not sign. Disconnect and lock end the batch. Protocol tests without `confirmSilentPublic` still follow the silent firmware path. That flag is not a Ledger wire MATCH.
- VoiceOver and TalkBack hear a word index, not the recovery words.
- BLE disconnect clears the link, the allowed central, and the pairing code. iOS does not expose a link key.
- CWS Proxy does not store a seed. Its log redacts a 12-or-more-word line and long hex. It remains transport only.

## 繁體中文（香港）

CWS 是一款手機模擬器，供開發者及錢包團隊測試與指定 Ledger、Trezor 及 OneKey 藍牙型號的互通。它不是安全元件。Ledger、Trezor 及 OneKey 均未認可本軟件。請勿以本軟件保管真實數碼資產。

**種子不是硬體錢包級安全。** 公開說明見 [docs/security.md](https://github.com/yanshekki/ysk-cold-wallet-simulator/blob/main/docs/security.md)。

### 1.1.1 改變了甚麼

- 正式組建以 `requireAuthentication` 儲存熵及 SLIP-39 份額。除錯組建只在 `__DEV__` 為真時略過提示。第一次成功讀取會留在記憶體，直至鎖定。顯示與備份會再次讀取鑰匙圈。
- 助記詞不會寫入剪貼簿。匯入只在確認貼上之後讀取剪貼簿；若剪貼簿仍是該段文字，匯入成功後會清除它。
- Android 正式組建在秘密畫面設定 `FLAG_SECURE`。略過只在 `__DEV__` 為真時存在。
- iOS 模糊應用程式切換器，並在系統報告截圖時警告。只警告是有意的：塗黑即時畫面亦會塗黑鏡像輸出與控制中心。
- 手機確認公開帳戶或擴展公鑰的讀取。一次確認涵蓋該次讀取，以及其後 60 秒內的 15 次公開讀取。它不會簽署。中斷連線與鎖定會結束這批確認。沒有 `confirmSilentPublic` 的協議測試仍跟隨韌體的靜默路徑。這個旗標不是 Ledger 線路 MATCH。
- VoiceOver 與 TalkBack 讀出詞序，不讀出助記詞。
- 藍牙中斷連線會清除連結、已允許的中央裝置及配對碼。iOS 不提供連結金鑰。
- CWS Proxy 不儲存種子。日誌會遮蓋十二個或以上的詞，以及長十六進位字串。它仍然只是傳輸。
