# CWS 1.1.7 (build 13)

YSK Limited · phone `hk.ysk.cws` · CWS Proxy `hk.ysk.cws.proxy`

Product: https://ysk.hk/products/ysk-cold-wallet-simulator

This note covers what landed after 1.1.6 (build 12): a visible preparing-wallet overlay after Face ID / fingerprint / device passcode, so the phone is not a frozen passphrase sheet while the wallet is prepared. It does not attach binaries. Signing identities and keystores are not in git. Seeds are not absolutely safe, and they are not hardware-wallet safe.

## English

CWS is a phone simulator for developers and wallet teams testing interoperability with selected Ledger, Trezor, and OneKey Bluetooth models. It is not a secure element. Ledger, Trezor, and OneKey do not endorse it. Do not use it to hold real digital assets.

**Seeds are not absolutely safe.** The public statement is [docs/security.md](https://github.com/yanshekki/ysk-cold-wallet-simulator/blob/main/docs/security.md). The 1.1.6 baseline still applies.

### What 1.1.7 changes

- After the user taps Apply on the session passphrase sheet, a full-screen loading overlay (“Preparing wallet…” / 「正在準備錢包…」) is shown before the OS authenticator. It stays up after Face ID, Touch ID, fingerprint, or device passcode succeeds, until seed materialisation finishes. Cancel leaves the sheet open with the input intact and does not toast. A ~20 second watchdog removes the overlay. The overlay does not show a fingerprint, passphrase, or mnemonic, and it does not say encrypt or decrypt.
- The same overlay covers clear-passphrase (no extra authenticator; the same KDF still runs), generate/import save (including a possible second Keychain prompt), vault backup, and account inspect including Cardano. Start advertising keeps its overlay and uses the preparing-wallet copy during the KDF, then “Starting Bluetooth…”.
- Unlock still uses the existing button busy state (“Unlocking…” / 「解鎖中…」). Debug builds still skip the OS reauth, so the blank gap is a release-build issue.
- `requireAuthentication` and SecureStore options are unchanged. CWS Proxy is unchanged and remains 1.1.6 (build 12).

## 繁體中文（香港）

CWS 是一款手機模擬器，供開發者及錢包團隊測試與指定 Ledger、Trezor 及 OneKey 藍牙型號的互通。它不是安全元件。Ledger、Trezor 及 OneKey 均未認可本軟件。請勿以本軟件保管真實數碼資產。

**種子並非絕對安全。** 公開說明見 [docs/security.md](https://github.com/yanshekki/ysk-cold-wallet-simulator/blob/main/docs/security.md)。1.1.6 的基線仍然適用。

### 1.1.7 改變了甚麼

- 在工作階段密語表按「套用」後，會在系統認證之前顯示全螢幕載入層（「正在準備錢包…」／“Preparing wallet…”）。Face ID、Touch ID、指紋或裝置密碼成功後，載入層會留到錢包準備完成。取消會留下該表及已輸入內容，不彈錯誤。約 20 秒的監察會移除載入層。載入層不顯示錢包指紋、密語或助記詞，也不說加密或解密。
- 同一載入層涵蓋清除密語（不再問認證；同一套金鑰衍生仍會執行）、產生／匯入儲存（包括可能出現的第二次 Keychain 提示）、種子備份，以及帳戶檢查（包括 Cardano）。開始廣播仍用原有遮罩，金鑰衍生期間改用「正在準備錢包…」，其後才是「正在啟動藍牙…」。
- 解鎖頁仍用原有按鈕忙碌狀態（「解鎖中…」／“Unlocking…”）。除錯組建仍略過作業系統再認證，因此空白空隙是正式組建才完整出現的問題。
- `requireAuthentication` 與 SecureStore 選項沒有改動。CWS Proxy 沒有改動，仍為 1.1.6（組建編號 12）。
